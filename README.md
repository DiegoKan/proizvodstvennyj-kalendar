# Производственный календарь России 2026–2027 (JSON)

Открытые данные: каждый день года с типом `work` (рабочий), `short` (сокращённый предпраздничный), `weekend` (выходной), `holiday` (нерабочий праздничный). Пятидневная рабочая неделя.

| Год | Рабочих дней (вкл. сокращённые) | Праздничных | Выходных |
|---|---|---|---|
| 2026 | 247 | 14 | 104 |
| 2027 | 247 | 14 | 104 |

Файлы: [`2026.json`](2026.json), [`2027.json`](2027.json).

```js
const cal = await (await fetch("https://raw.githubusercontent.com/DiegoKan/proizvodstvennyj-kalendar/main/2027.json")).json();
const isWork = d => ["work", "short"].includes(cal.days.find(x => x.date === d)?.type);
```

Основание: ст. 112 Трудового кодекса РФ и постановления Правительства РФ о переносе выходных дней. Календарь с переносами, нормами часов, PDF для печати и виджетом для сайта — на [rabochie-dni.ru](https://rabochie-dni.ru/2027/).
